# 🚀 Simple Login Pages

Welcome to **Simple Login Pages**, a beginner-friendly Open Source project where developers can showcase creative and responsive login page designs using **HTML and CSS**.

Whether you're making your **first Pull Request** or improving your frontend skills, this repository is the perfect place to contribute.

---

## ✨ About the Project

This repository is a collection of beautiful login page designs created by developers from around the world.

Each contributor adds **one HTML file** containing a complete login page (HTML + CSS).

Every accepted contribution will be showcased on the project's homepage.

## 🎯 Contribution Rules

* ✅ Create one HTML file inside the Contributors folder.
* ✅ Name the file using your GitHub username.
* ✅ Write all HTML and CSS in the same file.
* ✅ Make your design responsive.
* ✅ Submit only original work.


## 🚫 Do Not

* ❌ Edit another contributor's file.
* ❌ Create folders inside the Contributors directory.
* ❌ Add unnecessary files.
* ❌ Submit copied or plagiarized designs.



## 🚀 How to Contribute

1. Fork this repository.
2. Clone your fork.
3. Go to the Contributors folder.
4. Create a file named:

your-github-username.html


5. Add your complete login page code.
6. Commit your changes.
7. Push your branch.
8. Open a Pull Request.
