# Contributing to Simple Login Pages

Thank you for your interest in contributing! 🎉

We welcome everyone, whether this is your first Open Source contribution or you're an experienced developer.

## How to Contribute

1. Fork this repository.
2. Clone your fork to your local machine.
3. Navigate to the `Contributors` folder.
4. Create a new HTML file using your **GitHub username**.

Example:
Contributors/
└── your-github-username.html


5. Add your complete login page code to that file.

   * Use HTML.
   * Include all CSS inside a <style> tag.
   * No external CSS files.

6. Commit your changes.

7. Push your branch.

8. Open a Pull Request.

## Contribution Rules

* ✅ Use only one HTML file.
* ✅ Name the file with your GitHub username.
* ✅ Keep all CSS inside the same HTML file.
* ✅ Create an original login page.
* ✅ Make your design responsive.
* ✅ Test your code before submitting.


## Do Not

* ❌ Do not edit another contributor's file.
* ❌ Do not rename existing files.
* ❌ Do not create folders inside the Contributors directory.
* ❌ Do not submit copied or plagiarized designs.
* ❌ Do not include unnecessary files.


## Good Practices

* Use clean and readable code.
* Keep your HTML properly formatted.
* Use meaningful class names.
* Ensure the page works in modern browsers.


## After Your Pull Request

Once your Pull Request is reviewed and merged:

* Your HTML file will be added to the repository.
* Your login page will be showcased on the project's main index.html.
* You will become one of the project's contributors. 🎉

Happy Coding! 🚀
